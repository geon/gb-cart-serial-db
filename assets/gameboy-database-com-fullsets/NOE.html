NOE (for Nintendo Of Europe) is the code used for distribution in Germany, but why use a code that has nothing to do with the name of the country? The answer is simple: Nintendo's headquarters were in Frankfurt, Germany, which gave this country a really special place in Europe. There were several distributors in Germany, but one of the most important is certainly Laguna. Not really active at the beginning, Laguna increasingly took an important place in the market. NOE games were exported in neighbouring countries, but the best way to find NOE version of a game is to search in Germany directly. There are four exclusive NOE games; Hugo and Litti's Summer Sports are not counted because contrary to what one might think, Hugo is in tact the same game as Mickey Mouse, while Litti is the same game as Track Meet (only with slight differences in character design and title screens). lt is interesting to know that there are eleven other games that only exist as NOE versions in Europe: Altered Space, Attack of the Killer Tomatoes, Avenging Spirit, Brainbender, Hyperdunk, Matthias Sammer Soccer, Mickey's Ultimate Challenge, Pop'n TwinBee, RoboCop versus the Terminator, Tail 'Gator and WCW Wrestling the Main Event.
