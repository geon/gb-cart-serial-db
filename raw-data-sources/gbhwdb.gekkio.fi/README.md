# gbhwdb.gekkio.fi

Cartridge data export from the Game Boy hardware database by Gekkio and contributors (https://gbhwdb.gekkio.fi/cartridges/). Each row is one physical cartridge, photographed and documented by a contributor.

| File             | Downloaded from                                         |
| ---------------- | ------------------------------------------------------- |
| `cartridges.csv` | https://gbhwdb.gekkio.fi/static/export/cartridges.csv   |

Downloaded 2026-09-21. The file is unmodified.

The data is licensed under Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0): data derived from it must credit gbhwdb and be shared under the same license.

Imported to `data-sources/gbhwdb.gekkio.fi.json` with `npm run import:gbhwdb.gekkio.fi`.
