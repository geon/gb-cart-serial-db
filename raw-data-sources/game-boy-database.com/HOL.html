HOL (for HOLland) is the code used for distribution in the Netherlands. Contrary to what one might think, none of these games were translated in Dutch. They are all in English. HOL distributors are not exclusive to the Netherlands. Virgin Interactive, Nintendo or Laguna were active as HOL distributors, as in other countries.
Last point, it is interesting to note that one game, Hercules, exists with a NHOL box, but with a NOE cartridge (and not a HOL cartridge).
