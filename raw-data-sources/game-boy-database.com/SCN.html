SCN (for SCandiNavia) is the code used for distribution in Sweden, Finland, Norway and Denmark.
Bergsala was the official distributor for this localization, and it is interesting to point out that even now it is still Nintendo's official distributor in Scandinavia.
There are only two exceptions:

  • Worms, that was distributed by Ocean. lt is said that it was only sold in Denmark, explaining why this particular version of Worms is that rare.
  • Tintin i Tibet, distributed by lnfogrames.

    • Let's focus on the fact that the majority of SCN games were released before 1994: the explanation is that, given that the box/manual were always in English language, there was no difference between a SCN and an UKV version of the games. That's why since 1994, Bergsala partnered with English distributors to order and use the same boxes. This means that from the year 1994, games released in Scandinavia were only UKV or EUR cartridges. Many SCN games have been exported, especially to France, but the best way to find them is to search on Scandinavian websites.
    There is no exclusive SCN game, but we can focus on a particular SCN game, Bamse, that is the same game as Agro Saar, Baby T-Rex and We're Back, but with different character design.
