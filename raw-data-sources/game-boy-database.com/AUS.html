AUS (for AUStralia) means the code used for distribution in Australia and New Zealand. The historical distributor of this location is Mattel, which was subsequently supplanted by several others such as Metro or Nintendo quite simply.
AUS games were imported very little. Therefore, the best way to find them is to search Australian or New Zealand sites.
Note that Duck Tales and The Little Mermaid have a numbering that starts at -1, we have never seen the unincremented version.
There is no such thing as an exclusive game, but we can still highlight 4 here:

  • Agro Soar which is the same game as Baby T-Rex, Bamse and We’re Back but whose hero sprites and some elements of the game have been changed.
  • Game Boy Gallery 2, which is in fact the same game as Game & Watch Gallery with some modified background elements (not to be confused with Game Boy Gallery 2 in JPN which is a completely different game).
  • Legend of the River King GB and Ken Griffey Jr Presents Major League Baseball which have never been released in Europe so which are the only versions to have a round Nintendo seal.
