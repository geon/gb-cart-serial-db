# github.com/mstroh76/GBxDumper

`gbalist.csv` from GBxDumper, a Raspberry Pi based Game Boy (Advance) cartridge dumper by mstroh76 (hardware and software): https://github.com/mstroh76/GBxDumper

The program uses the list to look up the ROM size of Game Boy Advance cartridges, which isn't stored in the ROM. According to the README, it lists "alle bekannten GBA-Module" (all known GBA cartridges). The serials are built from the game code in the ROM header rather than read from cartridge labels.

| File          | Downloaded from                                                             |
| ------------- | --------------------------------------------------------------------------- |
| `gbalist.csv` | https://raw.githubusercontent.com/mstroh76/GBxDumper/master/gbalist.csv     |

The file is unchanged in the repository since its first commit, 2017-04-21. It was first downloaded 2026-09-23, and again 2026-10-15 to verify; both are identical. The file is unmodified.

Imported to `data-sources/github.com-mstroh76-GBxDumper.json` with `npm run import:github.com-mstroh76-GBxDumper`.
